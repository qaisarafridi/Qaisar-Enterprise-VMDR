**Qaisar Enterprise VMDR** is a cybersecurity project designed to centralize enterprise asset visibility, vulnerability tracking, contextual risk prioritization, and remediation management through an executive security dashboard.

## ✨ Key Features

* **Asset Inventory** — Centralized tracking of managed endpoints.
* **CVE & NVD Tracking** — Vulnerability records and CVSS severity assessment.
* **Contextual Risk Scoring** — Risk prioritization based on CVSS, asset criticality, CISA KEV, and remediation SLAs.
* **Remediation Management** — Track findings from discovery through resolution.
* **Endpoint Security Assessment** — Identify local security weaknesses and exposed services.
* **Compliance Reporting** — Executive HTML/PDF reports and CSV exports.
* **RBAC & Audit Logging** — Role-based access controls and security activity tracking.
* **Executive Dashboard** — Visualize security posture, vulnerability severity, and remediation progress.

## 🎯 Project Objective

To bridge the gap between vulnerability discovery and actionable risk management by helping security teams prioritize remediation based on technical severity and business context.

## 🛠️ Focus Areas

Vulnerability Management · CVE Intelligence · Endpoint Security · Risk-Based Prioritization · Security Automation · Compliance Reporting
